# Components

forgeui ships a focused set of accessible, themeable React components.

| Component | Purpose |
| --------- | ------- |
| `Button` | Actions with variants, sizes, loading and icon slots |
| `Input` | Single-line text input with validation states |
| `Select` | Native select with placeholder and option helpers |
| `Card` | Container with header, body and footer regions |
| `Badge` | Compact status label |
| `Tooltip` | Hover / focus label for a trigger element |
| `Tabs` | Accessible tab list with keyboard support |
| `Modal` | Focus-managed overlay dialog |
| `Toast` | Ephemeral notifications via context |
| `Table` | Typed data table |
| `Form` | Form wrapper with labelled fields and errors |
| `Spinner` | Loading indicator |

Every component is built with React and TypeScript, supports
`React.forwardRef`, and honours `prefers-reduced-motion` where relevant.
